# parseff-video

A launch film for [parseff](https://github.com/davesnx/parseff), written with [svjeez](https://github.com/saiashirwad/svjeez).

![Parseff launch film](parseff.svg)

```sh
bun install
bunx playwright-core install chromium-headless-shell
bun run dev     # live preview
bun run check   # svjeez check
bun run svg     # parseff.svg
bun run video   # out/parseff.mp4
```
